1. Overview

Personal Rclone Drive Sync is a private, personal project used exclusively by the application owner to synchronize and back up files between local workstations and Google Drive using the open-source software rclone. It is not offered as a commercial service or public web application.

2. Data Collection and Transmission

This application does not collect, log, aggregate, or transmit any user data or personal information to any third party, external server, or tracking platform:

  • No Telemetry or Analytics: There are no tracking scripts, cookies, analytics, or logging servers associated with this application.
  • Direct Communication: All network communication occurs directly between the local machine running rclone and Google's official API servers.
  • No Third-Party Sharing: No file contents, metadata, or Google account information are ever shared with or sold to third parties.

3. OAuth Credentials and Token Storage

When authenticating with Google via OAuth 2.0:

  • Authentication tokens are issued directly from Google to the local rclone client.
  • Tokens are stored strictly on the local file system within the user's private configuration file (typically ~/.config/rclone/rclone.conf).
  • Tokens are never uploaded to any remote host or external database.

4. Google User Data Access & Permissions

The application requests access to Google Drive scopes solely to perform file operations explicitly requested by the user via the rclone command line (such as copying, moving, syncing, or deleting files in designated directories).

The application complies with the Google API Services User Data Policy, including the Limited Use requirements.

5. Revocation of Access

Access can be revoked at any time by the account owner by visiting Google's Third-party apps with account access page at https://myaccount.google.com/permissions.
