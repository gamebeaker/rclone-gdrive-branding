# Personal Rclone Google Drive Sync - Branding & Privacy Policy

This repository hosts the static application home page and privacy policy required by Google Cloud Console for OAuth 2.0 consent screen branding.

## Published URLs

- **Application Home Page:** [https://gamebeaker.github.io/rclone-gdrive-branding/](https://gamebeaker.github.io/rclone-gdrive-branding/)
- **Privacy Policy:** [https://gamebeaker.github.io/rclone-gdrive-branding/privacy.html](https://gamebeaker.github.io/rclone-gdrive-branding/privacy.html)
- **Authorized Domain:** `curryplayer.github.io`

## Purpose

When setting up a personal Google OAuth 2.0 client ID for [rclone](https://rclone.org/drive/#making-your-own-client-id), Google Cloud Console requires valid branding URLs (Application Home Page and Privacy Policy) before allowing the consent screen to be published.

This repository provides those static assets via GitHub Pages.
